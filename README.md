# 🏨 Serenity Luxury Hotel

**Serenity** is a modern and elegant luxury hotel website designed to provide a premium and relaxing digital experience. The website features a beautifully designed landing page with luxury rooms, booking details, hotel experiences, wellness and spa services, local cuisine, nature activities, and a dedicated login page for guests.

The project focuses on creating a sophisticated, responsive, and user-friendly interface inspired by the concept of **slow living and luxury hospitality**.

## ✨ Features

* 🏨 Elegant luxury hotel landing page
* 🛏️ Multiple luxury room options with pricing
* 📅 Booking and availability section
* 🌿 Wellness & Spa experience
* 🍽️ Local cuisine and dining experience
* 🌊 Nature & adventure activities
* 🏡 Private villa and premium suites
* 🔐 Dedicated guest login page
* 🔑 Google and Facebook login UI
* 📱 Responsive and modern design
* ✨ Smooth hover and transition effects
* 🎨 Premium typography using Google Fonts

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, animations, and responsive design
* **Google Fonts** – DM Sans & Playfair Display
* **Unsplash** – Hotel and room images
